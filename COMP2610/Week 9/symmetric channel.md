A channel with inputs $\mathcal{A}_{X}$ and outputs $\mathcal{A}_{Y}$ and transition matrix $Q$ is [[symmetric relation|symmetric]], if $\mathcal{A}_{Y}$ can be partitioned into subsets $Y' \subseteq Y$ so that each submatrix $Q'$ containing only rows for outputs $Y'$ has 
	1: columns that are all [[permutation]]s of each other 
	2: rows that are all permutations of each other 

Importantly, only **one** partition needs to exist.
