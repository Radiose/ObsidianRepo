There is a fundamental tradeoff that occurs between the number of bits required in a uniform [[source code|lossy code]] and the probability of being able to code an outcome. 


![[Smallest delta sufficient subset]]


# Definition 
For an [[ensemble]] $X$, with $0 \leq \delta \leq 1$, the [[essential bit content]] of $X$ is 
$$H_{\delta}(X):=\log_{2}|S_{\delta}|$$
