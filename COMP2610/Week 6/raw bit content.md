[[source code|uniform coding]] give us a crude method to measure [[information]]. This is the number of bits required to assign equal length codes to each symbol.

# Definition 
if $X$ is an [[ensemble]] with outcomes set $A_{X}$, then its [[raw bit content]] is $H_{0}(X)=\log_{2}|\mathcal{A}_{X}|$



However, if we want to allow [[source code|lossy code]] to appear, we can come up with a different method of quantifying information.
