This is an analogue of the [[combination|choose]] function in combinatorics. 
The motivation is suppose you wanted to sort some set into 2 sets. Those that are in a set and those that aren't in a set. You can then use the choose function. However, what if you wanted to count the number of ways to arrange $N$ elements in a set into $I$ subsets? 

# Definition 

Given some set with [[cardinality]] $N$, the number of ways you can group its elements into $I$ subsets, each with size $n_{1},n_{2},\dots,n_{I}$  is given by $\frac{N!}{n_{1}!n_{2}!\dots n_{I}!}$
