A well defined expression is one that meets all criteria defined below: 
- If some input(typically a number) is represented in a different way, the output of the expression will still be the same. If $f(0.5)$ and $f\left( \frac{1}{2} \right)$ are not the same (assuming $f$ is some function with the domain being [[real number|reals]])
- The codomain and (more importantly, the) domain make sense. For example, if I have some function explicitly defined to be $f:\mathbb{R} \to \mathbb{R}$, $f(x)=\frac{1}{x}$, then the function is not well defined.
