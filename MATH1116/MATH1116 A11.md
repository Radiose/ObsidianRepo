### Continuity at 0
We aim to show that $\forall \epsilon\quad \exists\delta: \lVert x \rVert<\delta \implies \left\lvert  \frac{x_{1}^3-x_{2}^3}{x^2+x_{2}^2}  \right\rvert<\epsilon$
For simplicities sake, we define $y:=x_{2}$
$\lVert x \rVert=\lvert \sqrt{ \langle x,x \rangle } \rvert= \lvert \sqrt{ x^2+y^2 } \rvert<\delta$

Let $\epsilon>0$.
Choose $\delta$ such that $\delta=\frac{\epsilon}{2}$
Then
$\left\lvert  \frac{x^3-y^3}{x^2+y^2}  \right\rvert\leq \left\lvert  \frac{x^3}{x^2+y^2}  \right\rvert+ \left\lvert  \frac{y^3}{x^2+y^2}  \right\rvert$
Because $x^2,y^2 \geq 0$
$\left\lvert  \frac{x^3}{x^2+y^2}  \right\rvert + \left\lvert  \frac{y^3}{x^2+y^2}  \right\rvert \leq \left\lvert  \frac{x^2}{x^2+y^2}  \right\rvert\cdot |x| + \left\lvert  \frac{y^2}{x^2+y^2}  \right\rvert \cdot |y|$
$\leq |x| +|y| \leq 2 \sqrt{ x^2+y^2 }=2\delta= \epsilon$ 
Thus, $f$ is continuous at $0$.


### Admission of partial derivatives at 0 and subsequent lack of differentiability

We show that $f$ admits a partial derivative. 
$$\frac{ \partial f }{ \partial e_{1} }(0,0)=\lim_{ h \to 0 } \frac{1}{h}\left[ f(h,0)-f(0,0) \right] \\ \\ =\lim_{ h \to 0 } \frac{1}{h}\left[ \frac{h^3}{h^2} \right]=1$$
The same method applies to showing the existence of $\frac{ \partial f }{ \partial e_{2} }(0,0)$.


Finally, we note that continuity is necessary for differentiability (4.25 in lecture notes), thus $f$ is not differentiable at $0\quad \blacksquare$



# 2:

We aim to show that both partial derivatives of $g$ both exist, and are continuous. This implies that $g$ is differentiable, and immediately continuously differentiable.

First, note that multivariate MVT states that $$f(b)-f(a)=\nabla f\big((1-c)a+cb\big)\cdot(b-a).$$ (via Wikipedia)


In particular, we start with $\frac{ \partial g }{ \partial e_{1} }(x_{1},\dots,x_{n})$

$$\lim_{ h \to 0 } \frac{1}{h}[g(x_{1}+h,x_{2} \dots,x_{n})-g(x_{1},\dots,x_{n})] \\ \\ =\lim_{ h \to 0 } \frac{1}{h} \left[ \int_{0}^1 f(t,(x_{1}+h)t+\dots+x_{n}t^n)dt- \int_{0}^1f(t,x_{1}t+\dots+x_{n}t^n)dt \right] \\ = \lim_{ h \to 0 } \frac{1}{h}   \int_{0}^1 f(t,(x_{1}+h)t+\dots+x_{n}t^n)-f(t,x_{1}t+\dots+x_{n}t^n)dt $$

Call $y(t)=x_{1}t+\dots+x_{n}t^n$

We aim to show the integrand exhibits uniformity in order to exchange the limit and the integral.

To do this, we define $j_{k}(t)= \frac{f(t,y(t)+h_{k}t)-f(t,y(t))}{h_{k}}$ where $(h_{_{k}})_{\mathbb{N}}\in \mathbb{R}^\mathbb{N}$ , $h_{k}\xrightarrow[k \to \infty]{}0$ and $|h_{k}|\leq 1\ \forall k \in \mathbb{N}$

The pointwise limit of $j_{h_{k}}$ is obviously $\frac{ \partial f }{ \partial e_{2} }(t,x_{1}t+\dots+x_{n}t^n)$

Via the mean value theorem stated earlier, $j_{k}(t)=\nabla f((1-c)(t,y(t)+h_{k}t) +c(t,y(t))) \cdot(0,h_{k}(t))$

For simplicities sake, let $\xi=(t,\eta)$ with $\eta$ between $y(t)$ and $y(t)+h_{k}(t)$


$$f(b)-f(a)=\nabla f(\xi)\cdot(0,h_kt)=\partial_2 f(t,\eta)\,h_kt,$$

where $\xi=(t,\eta)$ and $\eta=\eta_k(t)$ lies between $y(t)$ and $y(t)+h_kt$. The $h_k$ cancels with the denominator.

$$j_k(t)=t\,\partial_2 f\big(t,\eta_k(t)\big).$$

**Difference from the limit.** Since $J(t)=t \frac{ \partial f }{ \partial e_{1} } (t,y(t))$,

$$j_k(t)-J(t)=t\Big[\frac{ \partial f }{ \partial e_{2} } \big(t,\eta_k(t)\big)-\frac{ \partial f }{ \partial e_{2} }  \big(t,y(t)\big)\Big].$$

Because $\eta_k(t)$ is between $y(t)$ and $y(t)+h_kt$, we have $|\eta_k(t)-y(t)|\le|h_k|t\le|h_k|$.

**Uniformity.** Let

$$K=\{(t,s):t\in[0,1],\ |s-y(t)|\le1\}.$$
This is closed and bounded, so it is compact, and it contains every $(t,\eta_k(t))$ and $(t,y(t))$ since $|h_k|\le1$. Assume $f\in C^1$ on an open set containing $K$. Then $\frac{ \partial f }{ \partial e_{2} }$ is continuous on the compact set $K$, hence uniformly continuous. 

Given $\varepsilon>0$, pick $\delta>0$ such that points of $K$ within distance $\delta$ have $\frac{ \partial f }{ \partial e_{2} }$-values within $\varepsilon$. If $|h_k|<\delta$, then for every $t\in[0,1]$ the two points $(t,\eta_k(t))$ and $(t,y(t))$ are within $\delta$, so

$$|j_k(t)-J(t)|\le t\,\varepsilon\le\varepsilon.$$

Hence $\sup_{[0,1]}|j_k-J|\to0$.

Since $(h_k)$ was an arbitrary sequence with $h_k\to0$ and $h_k\ne0$, the limit as $h\to0$ exists and

$$\frac{\partial g}{\partial x_1}(x)=\int_0^1 t\,\frac{\partial f}{e_{2}} \big(t,x_1t+\dots+x_nt^n\big)\,dt.$$


And because the integral is continuous, $\frac{ \partial g }{ \partial e_{1} }(x_{1},\dots,x_{n})$ is continuous, because partial derivatives of $f$ are continuous.

Similar logic applies to $\frac{ \partial g }{ \partial e_{2} },\dots,\frac{ \partial g }{ \partial e_{n} }$.
So because all partial derivatives are continuous, $g$ is $C^1$

Let $T \in \mathcal{L}(V)$, and $V$ be a finite dimensional inner product space. 
Suppose there was some $U \subseteq V$ such that $T=P_{U}$ 
$\implies \forall \mathbf{v}\in V,\quad \exists \mathbf{u}\in U\ \ \exists \mathbf{w}\in U^\perp: \mathbf{v}=\mathbf{u+w}$ 

So for $\mathbf{v_{1}},\mathbf{v_{2}}\in V$
$\langle \mathbf{v_{1}},\mathbf{v_{2}} \rangle=\langle \mathbf{u_{1}}+\mathbf{w}_{1},\mathbf{u}_{2}+\mathbf{w}_{2} \rangle$
So, $\langle T\mathbf{v}_{1},\mathbf{v}_{2} \rangle=\langle \mathbf{u}_{1},\mathbf{u_{2}}+\mathbf{w}_{2} \rangle$
$=\langle \mathbf{u}_{1},\mathbf{u}_{2} \rangle+\langle \mathbf{u}_{1},\mathbf{w}_{2} \rangle$
$= \langle \mathbf{u}_{1},\mathbf{u}_{2} \rangle$  (via definition of orthogonal complement)
And because $T=P_{U}$, $T(\mathbf{v}_{2})=\mathbf{u}_{2}$
So $\langle T\mathbf{v}_{1},\mathbf{v}_{2} \rangle=\langle \mathbf{v}_{1},T\mathbf{v}_{2} \rangle$ so $T$ is self adjoint.


$\implies$
Let $T \in \mathcal{L}(V)$, be self adjoint. 
Notice that $V=\ker(T) \oplus range(T)$
$\implies V=\ker(T^*) \oplus range(T)$     ($T$ is self adjoint)
Note as well that $\ker(T^*) =range(T)^\perp$
Let $\mathbf{v}\in V$
$\implies \exists \mathbf{u} \in \ker(T^*)^\perp,\ \ \exists \mathbf{w}\in range(T)$ such that $\mathbf{v}=\mathbf{u}+\mathbf{w}$
$\implies T(\mathbf{v})=T(\mathbf{u})+T(\mathbf{w})$
$\implies T(\mathbf{v})=T(\mathbf{w})$
Because $\mathbf{w}\in Range(T),\exists \mathbf{x}\in V$ such that $T(\mathbf{x})=\mathbf{w}$
$\implies T(\mathbf{v})=T(T(\mathbf{x}))$
But because $T^2=T$
$T\mathbf{v}=\mathbf{w}$ 
Thus, $T=P_{U}$, where $U=range(T)$

Let $T$ be normal. Let $\mathbf{v}\in V\setminus \{ \mathbf{0} \}$
Then,
$\lVert T\mathbf{v} \rVert=\sqrt{ \langle T\mathbf{v},T\mathbf{v} \rangle }=\sqrt{ \langle \mathbf{v},T^*T\mathbf{v} \rangle }= \sqrt{ \langle \mathbf{v},TT^*\mathbf{v} \rangle }$ via normality of $T$
$=\sqrt{ \langle T^*\mathbf{v},T^*\mathbf{v} \rangle }=\lVert T^*\mathbf{v} \rVert$

$\impliedby$
Let $\mathbf{v}\in V\setminus \{ \mathbf{0} \}$
Let $\lVert T\mathbf{v} \rVert=\lVert T^*\mathbf{v} \rVert$
$\implies \sqrt{ \langle T\mathbf{v},T\mathbf{v} \rangle }=\sqrt{ \langle T^*\mathbf{v},T^*\mathbf{v} \rangle }$
$\implies \langle T\mathbf{v},T\mathbf{v} \rangle=\langle T^*\mathbf{v},T^*\mathbf{v} \rangle$
$\implies \langle \mathbf{v},T^*T \mathbf{v}\rangle-\langle \mathbf{v},TT^*\mathbf{v} \rangle=\mathbf{0}$
$\implies \langle \mathbf{v},(T^*T-TT^*)\mathbf{v} \rangle=\mathbf{0}$
$\implies (T^*T-TT^*)\mathbf{v}=\mathbf{0}$ ( via inner product axioms and $\mathbf{v}\not= \mathbf{0}$)
$\implies T^*T\mathbf{v}=TT^*\mathbf{v}\quad \forall \mathbf{v}\in V$
$\implies T$ is normal

$\lVert T^*\mathbf{u}_{1} \rVert=\lVert T\mathbf{u}_{1} \rVert= \lVert \lambda \mathbf{u}_{1} \rVert=\lvert \lambda \rvert^2 ||\mathbf{u}_{1}||=\lvert \lambda \rvert^2$ ($\mathbf{u}_{1}$ has norm 1)

We know $\overline{T^*\mathbf{u}_{1}}=\overline{a_{11}}\mathbf{u}_{1}+\dots+\overline{a_{1n}}\mathbf{u}_{n}$ and $\overline{a_{11}}=\lambda$
$\implies ||\overline{T^*\mathbf{u}}||= \lvert \overline{\lambda} \rvert^2 +\dots+ \lvert a_{1n} \rvert^2=\lVert T\mathbf{u}_{1} \rVert=|\lambda|^2$

$\implies$ 
Suppose $T$ is diagonalisable wrt some orthonormal basis of $V$. This implies via the complex spectral theorem proven in class that $T$ is self adjoint. This implies that $TT^*=TT=T^*T$ meaning $T$ is normal.

$\impliedby$
Suppose that $T$ is normal.

We run strong induction on $n=\dim(V)$ with the claim that $T$ is diagonalisable wrt some orthonormal basis. 

For $n=1$, the argument is trivial, as any vector with norm $1$ can act as an ONB.

For the inductive case, suppose $\dim(V)=n>1$. We assume that it has a diagonalisable form in some orthonormal basis of $V$ for $\dim(V)=1,\dots,n-1$

Note that $V$ is a complex vector space, so algebraically closed and therefore must have some associated eigenvalue with eigenvector $\mathbf{v}$. Call $\mathbf{u}= \frac{\mathbf{v}}{\lVert \mathbf{v} \rVert}$.  Define $U=span \{ \mathbf{u} \}$. Note that because $T$ is normal, via (c), $U^\perp$ is $T$ invariant.  

Now let $S=T|_{U^\perp}$. For $x,y\in U^\perp$ we have $\langle Sx,y\rangle=\langle x,T^*y\rangle$ with $T^*y\in U^\perp$, so $S^*=T^*|_{U^\perp}$. Then  
$SS^*=TT^*|_{U^\perp}=T^*T|_{U^\perp}=S^*S$ so $S$ is normal. So the hypothesis applies to T restricted on $U^\perp$.

Recall the inductive hypothesis, and note that $U^\perp$ has dimension $n-1$. Thus, its ONB $\{ \mathbf{u}_{2},\dots,\mathbf{u}_{n} \}$ of eigenvectors is orthogonal to $U$ and thus $V=U \oplus U^\perp$ (via dimension count),giving $T$ a basis of eigenvectors and thus making it diagonalisable. $\blacksquare$
