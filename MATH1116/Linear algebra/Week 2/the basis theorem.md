let $V$ be a [[vector space]], with $dim(V)=n\geq 1$
i) Any [[linearly independent]] set of $n$ elements is a [[basis]] for $V$
ii) Any set of $n$ elements that [[span]]s $V$ is a [[basis]].

### Proof 
For part i), if $X$ is a [[linearly independent]] set, we can extend it to a basis $B \supset X$ of $V$, via [[basis#Theorem 2 (linear independent list extends to a basis)|this theorem]]. By corollary, and definition of dimension, B has $n$ elements in it, so we havent added anything, and then $X=B$ is a basis because any two bases have the same dimension. 
For ii), if $Y$ is a spanning set that contains $n$ elements, we find a subset $B \subseteq Y$ that forms a basis of $V$. Again, because any two bases have the same dimension, $B$ has the same number of elements as $Y$, and so $Y=B$ is a basis.
