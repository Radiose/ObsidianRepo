# Definition
A scalar $\lambda \in \mathbb{F}$ is an eigenvalue if $T-\lambda id$ is not [[Injective transformation|injective]], where $T \in \mathcal{L}(V)$
so $\lambda$ is an eigenvalue if $\ker(T-\lambda I)\not= \{ \mathbf{0} \}$
# Remark 
$\lambda$ is an eigenvalue $\iff$ there exists $\mathbf{v}\in V \setminus \{ \mathbf{0} \}$ such that $T\mathbf{v}=\lambda \mathbf{v}$
From this, $Tv-\lambda v=0$
$\implies(T-\lambda I)v=0$
So, if $(T-\lambda I)$ is not injective, then there exists a $v$ that satisfies the above.
