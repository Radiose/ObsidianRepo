# Definition 
A set of vectors $\{ \mathbf{e_{1}},\dots,\mathbf{e}_{n} \}$ in $V$ are orthonormal if $\langle \mathbf{e}_{i},\mathbf{e}_{j} \rangle=\delta_{i,j}$
