inductive reasoning

This is the form of reasoning that starts out with empirical data, and from there, we create our hypothesis and theory backwards. 

Empirical data will lead to hypothesis via learning, and then we attempt to generalise it to get a theory.

# Use in machine learning 
machine learning is based on inductive reasoning. This means it suffers from the same problems as any other inductive science.  
Suppose some machine learning model is so flexible it can fit any possible dataset perfectly. Then, we have some model that can never be falsified by data.
