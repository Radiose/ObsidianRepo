# Types of machine learning 
Every machine learning problem involves some inputs.
The difference between the types of machine learning is what else we have available. Are labels or outcomes observed for each input? Or is there a feedback signal instead of a fixed dataset?

This gives us three broad types of machine learning.
![[supervised learning]]
![[unsupervised learning]]
![[reinforcement learning]]

## Simple overview 
Supervised: inputs and labels observed, goal is prediction 
unsupervised: only inputs, goal is structure discovery
reinforcement: no fixed data, agent generates it through interaction and feedback
All three share the same inductive challenge, which is to generalise beyond what is given in the training data.
