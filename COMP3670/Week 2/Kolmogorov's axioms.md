Probability measure 
a function $\mathbb{P}$ that assigns to each event $A \in S$ a number $\mathbb{P}(a)$ and satisfies 
$0 \leq \mathbb{P}(a) \leq {1}$ for any event $A$ 
$\mathbb{P}(\Omega)=1$
if $A_{1},A_{2}\dots$ are [[Pairwise disjoint]], then $\mathbb{P}(U_{i\geq_{1}A_{i}})= \sum _{i\geq 1}\mathbb{P}(A_{i})$ These are also known as Kolmogorov's axioms.
