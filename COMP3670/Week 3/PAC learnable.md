A hypothesis set $\mathcal{H}$ is PAC learnable if there exists a learning algorithm and a function $H_{\mathcal{H}}(\epsilon ,\delta)$ such that for every $\epsilon,\delta \in(0,1)$ and every distribution, $P$, if the sample size $N \geq N_{\mathcal{H}}(\epsilon,\delta)$, then the learned hypothesis satisfies $$\mathbb{P}(E_{out}(\hat{h}_{N})<E_{out}(h^*)+\epsilon)\geq 1-\delta$$ with $\hat{h}_{N}$ being the learned hypothesis.
