Setter method
A setter method is a [[Method]] that allows private [[field]]s to remain hidden from the user while changing them, allowing the continuity of [[Encapsulation]] in a program. This is very important, as creating a public [[field]], while it may seem to be a better solution, can cause unwanted side effects. 

Setter methods allow for [[Exception]]s to be thrown when desired.

Getter methods are a method that returns the value of a private [[field]] when desired. They allow for immutable data, as it can make fields read only, rather than public fields which can be modified externally.
