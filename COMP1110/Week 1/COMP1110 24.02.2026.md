comparison of string values
Strings in java cannot have their values tested by simple == such as in haskell.
This is because the == will instead test if the two strings identical in terms of memory, as in theyre both stored in the same location in the computer. To test the actual equalities, we use `.equals(string)`. For example 
```java
if (input.equals ("yes")){
	IO.println(...);
	}else{
	IO.println(...);
	}
}
```
This code block basically tests whether the string assigned with variable name `input` is `"yes"`
