Big o complexity

O(n) - 
$f(n) \in O(g(n)) \iff \exists n_{o} \exists c>0 \ \forall_{n\ge n_{o} } f(n) \le  c \times g(n)$
A [[Function]] f of x is in the set of O of g of x if and only if, there exists constants n and c such that for all x greater than n,  f(x) is less than or equal to c times g(x).

Big O complexity refers to the **upper bound** of the function 
- this can be observed by f(n) is always LESS than or equal to c times g of (n)
