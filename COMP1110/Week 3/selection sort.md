selection sort:
select minimum element, and then swap it with the current index. 
for a deck of 8 cards. compare 8 cards, then 7 cards, then 6 cards etc. Generally would be considered O(n^2) complexity. It is in the order of n^2.

Mathematically, it has n-1+n-2+n-3... 1 comparison
using an arithmatic sequence 
$\frac{n(n-1)}{2}$
