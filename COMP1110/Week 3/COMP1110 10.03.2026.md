All functions in java store their variables locally inside them. 
With [[Array]], the variable itself is the reference. array[0] is telling you where the array is being stored. 
so 

```java
void function (int[] arr) {
arr[0] = 100;
}


void main(String[] args){
int[] array = new int[]{1,2,3,4,5}

}
```
This will change the first value stored in the array 

```java
void function (int[] arr) {
arr = new int[]{-1,-2}
}


void main(String[] args){
int[] array = new int[]{1,2,3,4,5}
function(array)
IO.println(array)
}
```
In the above block, the array will print the positive numbers. This is because the location that `array` points to has not changed in the main code block. All that has happened is in the actual function up top, arr has been redefined. 
Compare this 
```java
void anotherFunction(int x) {
x = 100
}
```
If i pass ```java
	int x =2 
	anotherFunction (x)
	IO.println(x);
	```
this will not change the original x. This is because the x is stored locally within the function.
