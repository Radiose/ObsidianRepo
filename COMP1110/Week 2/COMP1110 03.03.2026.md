Simple guessing game
This game relies on guessing a number in a range *n*. The method for guessing the number is to get the halfway point in the range, and then getting the feedback on whether the number we are trying to guess is more or less than this number. This process is then repeated for halfway between the next range that you obtain from the previous feedback, so this looks like 0-100 50H - 75L - 62.5 L - 56.25 etc. 

`Integer.parseInt(str)` will make you get an integer from a string. If the string given is not contained of numbers, the program will crash
