Arrays
similar to strings, are defined by their location in memory, not contents 
Their type: type of content they contain plus square brackets
Eg `int[] arr = new int [10];`
this will give an array at a location in memory, with int comprising 10 integers, with their default value being zero
`int[] arr = new int [5]{101,5,-8,8000000,0,1};`

Arrays are an example of a mutable data type.
