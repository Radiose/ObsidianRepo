Test suite 
One method of testing in a program is to create a test suite, which is a form of [[Class]]. Each [[Method]] within the test suite is a **test case**. 

The advantage of using a test suite is mainly structure and simplicity. It allows for simple *test driven development*, as opposed to [[testing with assert]] in the [[Main]] function, which is fine for smaller algorithms, but for large projects, will often make things awkward.
