## The chat history full code 
```java
// File: ChatHistory.java
public interface ChatHistory {
  /** Adds a new message to the history. */
  void addMessage(String msg);
  
  /** Prints messages in reverse chronological order. */
  void display();
}
```

Chat history is a [[non sealed interface]] with the [[Method]]s addMessage and display


```java
//File: CircularBufferChatHistory.java
class CircularBufferChatHistory implements ChatHistory {
  private String[] arr;
  private int nextAvailable;
  private int size;

  CircularBufferChatHistory(int capacity) {
    this.arr = new String[capacity];
    this.nextAvailable = 0;
    this.size = 0;
  }

  public void addMessage(String msg) {
    this.arr[nextAvailable] = msg;
    nextAvailable = (nextAvailable + 1) \percent this.arr.length;
    if (this.size < this.arr.length) {
      this.size = this.size + 1;
    }
  }

  public void display() {
    int i = 0;
    int idx = (this.nextAvailable - 1 + this.arr.length) \percent this.arr.length;
    while (i < this.size) {
      IO.println(this.arr[idx]);
      idx = (idx - 1 + this.arr.length) \percent this.arr.length;
      i = i + 1;
    }
  }
}
```
`CircularBufferChatHistory `is a class that implements `ChatHistory` [[non sealed interface|interface]].


```java
//File: LinkedListChatHistory.java
class LinkedListChatHistory implements ChatHistory {
  record ChatLL(String msg, ChatLL rest) {};
  private ChatLL list;

  LinkedListChatHistory() {
    this.list = null;
  }

  public void addMessage(String msg) {
    this.list = new ChatLL(msg, this.list);
  }

  public void display() {
    ChatLL current = this.list;
    while (current != null) {
      IO.println(current.msg());
      current = current.rest();
    }
  }
}
```

`LinkedListChatHistory` is another class that implements the ChatHistory [[non sealed interface|interface]]

```java
// We can swap the implementation without changing the code that uses it
ChatHistory myChat = new LinkedListChatHistory(); 
myChat.addMessage("Hello!");
myChat.display();
```

`myChat` could either be `LinkedListChatHistory`, or `CircularBufferChatHistory`, the code beneath it would be the same.

```java
// File: ErasableChatHistory.java
interface ErasableChatHistory extends ChatHistory {
  void erase();
}
```

```java
// File: LinkedListChatHistory.java
class LinkedListChatHistory implements ErasableChatHistory {
  record ChatLL(String msg, ChatLL rest) {};
  private ChatLL list;

  public void addMessage(String msg) {
    this.list = new ChatLL(msg, this.list);
  }

  public void display() {
    ChatLL current = this.list;
    while (current != null) {
      IO.println(current.msg());
      current = current.rest();
    }
  }

  public void erase() {
    this.list = null;
  }
}
```

This is a class that implements an interface that extends another [[non sealed interface|interface]]. 

Note that the **type** is the key to determining whether an object will will be able to implement methods, even if the object was called from a different [[Class]]

```java
// The variable type is ChatHistory
ChatHistory myChat = new LinkedListChatHistory();
myChat.addMessage("Hello"); // OK: Defined in ChatHistory
myChat.display();           // OK: Defined in ChatHistory

// myChat.erase();          
// ERROR: The compiler only sees a ChatHistory, 
// and ChatHistory does not have an erase() method.
```

As shown above, ChatHistory is the original [[non sealed interface|interface]] that the classes implemented.
