functional programming 
two presets of functional programing
 1: [[Class mutability|immutable]] data 
	  similar to mathematical definitions - immutability mainly 
 2: First class functions : (or [[function]]s as values)
	 functions are values like any other value - can make functions that return functions 
	 is very useful 

The final keyword is what makes something immutable. Note that for [[reference type]]s, final will make the address immutable, but the actual thing itself can be changed IE a final set can have elements added
