You rewrite this with function<a,b> where it outputs B and has A as input 
```java
<A,B> B fold(BiFunction<A,B,B>f, List<A>l){
	B result;
	for(A i : l){
		result = f.apply(i, result);
	}
	return result;
}
```

You can call functions like this 
```java
Integer sum = fold(Integer::sum, 0, divisibleBy3);
```
where Integer::sum is a prebuilt funciotn 

These are not super efficient with [[space complexity]]. 



stream methods 
```java
Integer sum2 = test.stream().map((x) -> x-2)
```
