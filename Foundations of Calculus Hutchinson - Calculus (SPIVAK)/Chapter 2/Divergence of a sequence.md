If a [[Sequence]] does not [[Convergence of a sequence|converge]], we say conversely that it diverges. We write $$\lim_{ n \to \infty }a_{n} = \infty$$
if 
$\forall M \in \mathbb{R}\ \ \exists n \in \mathbb{Z} \ \ \  \ n>N \implies a_{n}>m$
For every real number M, there exists an integer N, where if a number n is greater than N, then the nth element in the sequence is *greater* than the real number M


We write   $\lim_{ n \to \infty }a_{n} = -\infty$ 

if for each [[real number]] $M$ there exists an integer $N$ such that  $\forall M \in \mathbb{R}\ \ \exists n \in \mathbb{Z} \ \ \  \ n > N \implies a_{n}<M$
For every real number M, there exists an integer N, where if a number n is greater than N, then the nth element in the sequence is *less* than the real number M.
