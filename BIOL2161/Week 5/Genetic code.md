Genetic code
pretty much universal
consists of **triplet codons**
three nucleotides create an amino acid 
Different organisms have different preferences for which codons they prefer
**Degenerate** - the same amino acids can be coded by different triplets
Wobble - the first two are very strict  - the last nucleotide isnt as important

Some exceptions to genetic code 
Some organisms will encode a stop codon for different triplets 

Reading frames are very important when considering translating mRNA
