Base excision repair
in base excision repair, a modified base is excised, and then the entire nucleotide is replaces
the excision is catalysed by a set of enzymes called [[DNA]] glycolases. These recognise and remove a specific type of modified base by cleaving the bond that links that base to 1' carbon atom of deoxyribose sugar.

An AP(apurinic) site is one that is missing a base, but DNA backbone is still intact. This happens much more with [[Purine]]s, because they are significantly bigger than [[Pyrimidine]]s. 

From here, DNA endonuclease removes the backbone.

The base excision repair is catalysed by DNA pol $\beta$ .This is a more error prone form of DNA polymerase than the ones used in [[DNA replication]]. Of course, ligase is used as well to completely put it back in place. 

if DNA polymerase beta makes a mistake, the double helix will be slightly distorted 

Ligase is inefficient when there is a distortion 

Other systems can detect and repair the mistake
