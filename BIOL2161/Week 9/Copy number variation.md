Copy number variation 
[[Multigene family|gene family]]s are one example of copy number variation, but copy number variation can refer to any difference in copy number of any [[DNA]] sequence.
Individuals vary in the number of copies of a particular [[DNA]] sequence. 
CNV's affecting genes have functional implications, so the presence of more than one copy can affect the organism - you can get a gene dosage effect.
