Countable 
A set S is countable when there is a [[Bijective|bijection]] from S to a subset of the set N of natural numbers. 

Any finite [[set]] is countable

the empty set is countable  (because the empty set is a subset of the natural numbers)
The set of all primes is [[countable]]
the natural numbers are [[countable]]
