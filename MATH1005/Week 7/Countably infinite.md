Countably infinite
The sets $\mathbb{P}$ and $\mathbb{N}$ are both countable and infinite. 



A set S is countably infinite iff it is infinite and there is bijection from S to a subset of $\mathbb{N}$
However, any infinite subset S of $\mathbb{N}$ has the same cardinality as $\mathbb{N}$ itself

It follows that proving an arbitrary infinite set S is countably infinite if it can be 'well-ordered'

The most surprising fact:
The set of all rational numbers is [[Countable]]/countably infinite 

The set of all real numbers is uncountable. This is because there is no [[surjective function]] that can map $\mathbb{R}$ to $\mathbb{N}$

Idea: To show that a set A is countably infinite, you may describe a scheme for saying the elements of A out loud such that 
No element of A will be repeated (Injective)
No matter which element of A your friend is thinking of, you will eventually say it ([[surjective function|surjective]])
