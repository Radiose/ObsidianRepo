Positional notation 
let b, called the base be an integer that is at least 2, and let $d_{0},d_{1}\dots d_{b-1}$. Let these be called digits, that represent the first b non negative integers in order.

Any non negative integer number can be written in exactly one way using these digits and positional notation as follows. For any
($xi_{s}, xi_{s-1}\dots xi_{0}$)$_{b}$ means  $xi_{s}\times b^s+xi_{s-1} \times b^{s-1} + \dots xi_{0} \times b^0$ 

for example, in base 10 $(63403)_{10}$ represents this number $(6 \times 10^4+3 \times 10^3+4 \times 10^2+0 \times 10^1+3 \times 10^0)_{10}$
$(10111)_{2}$ = $(23)_{10}$

octal digits 
$(63403)_{8} = (26371)_{10}$

$(3AD0f)_{16}$
