Functions 
some [[relation]]s are functions 
let A,B be sets. A [[relation]] F from A to B is called a function from A to B when $\forall a \in A \exists!b\in B (a,b) \in f$
For every input, there is a unique output. 
The set A is the domain, while the set B is the codomain. 
The range of the function is 
$\{ b \in B|\exists a \in A(a,b) \in f \}$
or, the range is the [[subset]] of the codomain comprising the elements that are actually selected as outputs of the function


we write $f:A \to B$ to say that f is a function from A to B. Even though a function is a [[relation]],, we usually write f(a) = b instead of *afb*.


Every input gets used once. However, there can be several inputs that map to one output, however, each input gets mapped to only one output. 


To describe a function f you must

describe domain A
describe codomain B
specify enough about the function that you can make a [[predicate]] that is true for all a $\in$ A

When are two functions equal
If they have the same domain, same codomain, and f(x) = g(x) for all x in the domain

However, if you change domain and codomains to natural numbers, the function is well defined
