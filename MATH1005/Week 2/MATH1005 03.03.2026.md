String and languages:
Let a be a set. A string of length n over a (the alphabet) is an ordered n-tuple, written without parentheses or commas, in which every element is taken from a. The Null string over a is the string with no characters. The null string over A is denoted $\lambda$ and is said to have length 0. We write $A^*$ for the set of all string over the alphabet A. Any subset of $A^*$  is called a language.
