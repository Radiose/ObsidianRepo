powersets 
For any [[Set]] A, the power set of A, denoted $\mathcal{P}$(A) is the set of all subsets of A
For example, if A = {1,2,3}, then $\mathcal{P}(A) = \{\emptyset, \{ 1 \}, \{ 1,2 \}, \{ 1,2,3 \},\{ 1,3 \},\{ 2,3 \},\{ 2 \},\{ 3 \}\}$
A powerset of a set with n elements has $2^n$ elements.
