Ordered n-tuples
let n be a positive integer, and let $x_{1},x_{2}\dots n$ be (not necessarily distinct) elements. The ordered N tuple consists of $(x_{1},x_{2},\dots x_{n})$ together with the ordering. An ordered 2 tuple is called an **ordered pair**. An ordered 3-tuple is an **ordered triple**.

$(x_{1},x_{2}..x_{n})=(y_{1},y_{2}\dots y_{n})$ if x_1 = y_1 ^ x_2 = y_2 etc.
Tuples are only equivalent if they are the same dimension
The elements in ordered n-tuples do not need to be of the same type
We are however, usually interested in sets of ordered n-tuples where all of the elements in say, the i-th position are of the "same type".
