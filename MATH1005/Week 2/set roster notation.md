set roster notation 
a set s may be specified using set roster notation. 
This can be accomplished by writing all of its elements, with elements separated by commas and the entire collection enclosed by braces
Using ellipses ... (can be read as "so on")
The elements must establish enough of a patter in a way that is obvious to a reader, that it becomes clear how the pattern continues and whether or not the pattern ends.

Set roster notation is not perfect. The second that you identify more than 1 appropriate definition, the [[Axiom of extensionality]] indicates that the notation is flawed.
