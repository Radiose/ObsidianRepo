Identity matrix 
The basic matrix equation  $\begin{matrix}[1,0] \\ [0,1]\end{matrix} \times \begin{matrix}[a,b] \\ [c,d]\end{matrix}$  can show any 2x2 matrix through manipulation of A, B, C or D.

The identity matrix can be defined $i_{n}=(\delta_{i,j})\in M_{n}\mathbb{Q}$ with:
When Q=J, $\delta$ = 1
otherwise =0


The identity matrix $I_{n}$ for any $n \in \mathbb{N}$ has the property
 $\forall _a \in \mathbb{N}, \ \forall M\in M_{n}(\mathbb{Q})\ I_{n}M = M = MI_{n}$

The identity matrix has the same properties as the [[Standard Matrix]], as it is composed using similar methods.
