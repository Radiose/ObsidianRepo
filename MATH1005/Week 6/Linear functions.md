Linear functions 
Def
a function $f: Q^n \to Q^n$ is called **linear** if and only if 
(where Q^n is an n dimensional vector)

$\forall x, y\in Q^n \  F(x+y)=F(x) + F(y)$
$\forall x \in Q^n \ \ \forall \lambda \in Q   F(\lambda x)=\lambda F(x)$


to each linear function $F : Q^n \to Q^n$, there is a [[Matrix]] $M \in M_{n}(Q)$ such that $\forall x \in Q^n$ $f(x) = Mx$

This rule can be demonstrated through Squaring a [[Matrix]].
