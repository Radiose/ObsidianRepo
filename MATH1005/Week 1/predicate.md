predicate 
a sentence containing one or more variables with the property that, when a value from a specified domain is given to each variable, the sentence becomes a [[Statement]]. The specified domain is the domain of the predicate.

EG x is 8, and x is greater than 7. This is statement becomes true. 

A predicate will always have in mind the data type of the variable.

Another example: q(x): x is allowed to view this file
defined over a list of![[Proving an implication]] users. 

r(x,y): x shares a land border with y
x and y take values from the set of countries.
