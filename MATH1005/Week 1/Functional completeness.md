Functional completeness
You can determine whether you have the sufficient amount of logical connectives, by whether you can make a truth table with all combinations of true and falses. Functional completeness is when you construct the truth table with only the logical connectives.

You can just make a truth table full of $\land$, $\neg$, and $\lor$ to create an expression for any truth table. 

A set of logical connectives A is functionally complete if in any truth table, we may replace the statement form by one that is made using only statement variables, parentheses and connectives from A and still have a correct [[TRUTH TABLES]]
