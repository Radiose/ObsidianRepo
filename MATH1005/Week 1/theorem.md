The proof of this: consider a truth table of some arbitrary statement form that is not a contradiction. Using a conjection in which each statement variable or its negation appears but not both, we can make a statement form with the truth table in which there is exactly one T. By intentionally choosing between the statement variables and their negations, we can make that T be in any row of the truth table. 

To make a statement from to match any particular truth table, we note the rows in which t's appear, we use a conjunction for each such row and we combine these conjunctions into a disjunction.
