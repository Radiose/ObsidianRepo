Galileos model of free fall

Galileo proposed that, if we ignore air resistance, the distance fallen by any freely falling body is proportional to the square of the time it has been falling.

When an object falls from rest, the distance fallen d is related to the time since release t by
d(t) = 4.9t^2. 

Speed is the rate of chance of distance travelled. In our case, it will be measured in m.s^2

Models have the use of
1: making predictions by interpolating between measured data
2: make predictions by extrapolating 
3: compute unmeasurable or unmeasured quantities
4: explain certain observed aspects of phenomena 
5: help us understand how to make a system behave desirably by setting the values of some quantities that are easy to control 


Making an odometer 
describing the distance travelling by a cyclist, describing the distance travelled by only the number of rotations made by the front wheel. The wheel has a diameter 60cm

First step:
create variables
x denote the distance travelled by the cyclise
n denote the number of rotations 

second step 
make assumptions 
assume no slippage of the wheel against the wheel

third step:  mathematically reason 
reason that each rotation of the wheel corresponds to $0.6\pi m$ 

Then the relationship between x and n is described by $x = 0.6\pi n$

This model is a mechanistic model 

The domain of this function is the set of number from (0,$\infty$).
