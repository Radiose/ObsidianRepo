The [[Second Derivative]] test 

if f'(c) = 0 and f''(c)> 0, then c is a local minimum point of f 
if f'(c) = 0 and f''(c) < 0, then c is a local maximum point of f
If f''(c) = 0 or f''(c) DNE, then use [[The first Derivative test]].

Easier way to think about it: using [[The concavity test]], if the second derivative is positive, the tangent line is underneath the function. If its negative, its above the function. Therefore, a local minimum, with the tangent line beneath it, will have a positive [[Second Derivative]]
