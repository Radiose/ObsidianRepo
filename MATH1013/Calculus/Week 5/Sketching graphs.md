Sketching graphs
f is strictly increaseing on an interval I
x1<x2 $\implies$ f(x1)<f(x2)
F is non decreasing in I
$x_{1}<x_{2} \implies f(x_{1}) \le f(x_{2})$
F is strictly decreasing if 
$x_{1}<x_{2} \implies f(x_{1})>f(x_{2})$
non increasing if 
$x_{1}<x_{2} \implies f(x_{1})\ge f(x_{2})$


We utilise the [[Derivative]] to determine if a [[Function]] is increasing or decreasing 
if the [[Derivative]] is positive on interval I, it is increasing 
If derivative is negative, it is decreasing

All steps to take:
1: What is the domain of *f*
2: Y intercept is f(0), X intercepts are when f(x) = 0
3: symmetry 
	-  y axis symmetry when f(x) = f(-x)
	- symmetry by rotation of 180$^\circ$ about the origin if f(-x) = -f(x)
	- Periodicity if f(x+t) = f(x) for some number T
4: asymptotes
	- if $\lim_{ x \to \pm\infty }f(x)$ =L, there is a horizontal asymptote
	- if $\lim_{ x \to a^{\pm} }f(x)$ = $\pm \infty$, there is a vertical asymptote at a
5: intervals of increase/decrease 
6: local [[Maxima and minima|maxima or minima]] using [[The first Derivative test]] or [[The Second Derivative test]]
7:concavity, and [[Inflection point]]s determined by the sign of f''(x)
