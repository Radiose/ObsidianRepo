Odd and even functions

Symmetries across the origin, or the Y axis can be used to simplify the process of [[Definite integral|integration]].
These symmetries can be given by determining whether a given integrand is an odd, or an even [[Function]]. 

### Even functions
$\forall x (0,\infty)$, a function is even if $f(-x) = f(x)$. 
An example of this function is $f(x) = x^2$, the result of $f(x)$ will always be positive. 

Even functions will demonstrate a symmetry across the Y axis

### Odd functions
$\forall x (0,\infty)$, a function is odd if $f(-x) = -f(x)$. 
An example of this is $f (x) = x^3 + x$
$f(3) = 3\times3\times3+3$ = 30
$f(-3) = -3 \times -3 \times -3 -3$ = $-30$

Odd functions will demonstrate a symmetry across the origin.

## Use in [[Definite integral|integration]]
Computing an integral $\int_{-a}^a f(x)$ when f is an even function, can be computed as $\int_{0}^af(x)$

if f(x) is odd, $\int_{-a}^af(x) = 0$ because the net area cancels out. 

$\int_{-a}^a\sin(x)=0$, because sin is an **odd** function  
$\int_{-a}^a\cos(x)=2\int_{0}^a\cos(x)$, because cos is an **even** function.
