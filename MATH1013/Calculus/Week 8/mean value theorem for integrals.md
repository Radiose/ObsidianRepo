[[mean value theorem]] for integrals
## Rule
The average value of a [[function]] is given by $f_{ave}=\frac{1}{b-a}\int_{a}^b f(x)dx$

$f_{ave}\times(b-a)=\int_{a}^b f(x)dx$ 
$\implies \bar{f}=\frac{1}{b-a} \int_{a}^b f(x)dx$

## derivation from the original [[mean value theorem]]

$f'(c)=\frac{f(b)-f(a)}{b-a}$ or $f(c) = \frac{F(b)-F(a)}{b-a}$

$\int_{a}^b f(x)dx = F(b)-F(a) = f(c)(b-a)$
thus f(c) = $f_{ave}$

There exists some point c in the interval \[a,b] such that $f(c) = f_{ave}$


Note that this does note mean that there exists a unique c, there could be multiple c, and in fact *there often is.*
