Eulers number and the exponential 
exp(x), or [[Eulers number and the exponential|the exponential]] is denoted as the inverse function of ln(x)
 
Via the [[intermediate value theorem]], $(ln(1)=0)$ and $\lim_{ x \to \infty }\ln(x) = \infty$), there exists a value $a >1$ such that $\ln(a)=1$
Because ln is [[Injective Function|injective]], that value must be unique.
That value is $e$, $\ln e=1$
The [[Inverse function]] of $e^x$ is $\ln(x)$
([[Natural logarithm]])

Recall:
If r is a rational number, then $\ln(e^r)=r\ln(e)=r$
This is because $\ln(\exp r)=r$
so $\exp r = e^r$
We now define $e^x$ for all real numbers as well (adding irrational)

## Properties
There are some properties of the exponential function 
$e^x>0 \forall x$
$\lim_{ x \to -\infty }e^x=0$
$\lim_{ x \to \infty }e^x=\infty$

And perhaps the most important, the [[derivative]] of $e^x = e^x$
