Maxima and minima
The function has a global maxima if f(c) $\ge$ f(x) for all x in the domain of f. 
The function has a global minima if f(c) $\le$ f(x) for all x in domain f
These are also called extreme values 
A local maximum at point c is when f(c) $\ge$ f(x) for all values x in a neighbourhood of c.
A local minimum at point c is when f(c) $\le$ f(x) for all values x in a neighbourhood of c.
