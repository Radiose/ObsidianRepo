[[linearly independent]] [[Matrix]] columns
Recall that if A = $[a_{1},a_{2}\dots an]$, then saying that the equation Ax = 0 has no non trivial solutions is equivalent to saying  that the equation has only the trivial solution $x_{1}=x_{2}\dots x_{n}=0$ This can be expressed by saying the set of a1-an is linearly independent, or that all [[vector]]s are zero. 

We also said that for the equation Ax = 0 to have no non trivial solutions, there must be no free variables. 

The columns of A are [[linearly independent]]
The equation of Ax = 0 has only the trivial solution 
Every **column** of A has a pivot.

Therefore, for a matrix that has more rows than columns, there must exist a column without a pivot. This is by default [[Linearly dependent]]. There cannot be a 4 dimensional vector in a 3 dimensional space.

$v_{1}\dots v_{n}$ is [[Linearly dependent]] $\iff$ $\exists_{\vec{V_{k}}}\in{v_{1}\dots v_{n}}$
and that $\exists_{x} \in \{x_{1},x_{2}\dots x_{n}  \} \not= 0$
