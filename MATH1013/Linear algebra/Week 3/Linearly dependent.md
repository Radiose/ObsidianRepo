Linearly dependent
An equation is linearly dependent if  there are weights that are not all zero in a homogenous system. 
A system is linearly dependent if some of the [[vector]]s that comprise it are facing the same direction.
A system is linearly dependent if there are free variables in the echelon form of the [[Matrix]]. 


If there are more than n vectors in an $\mathbb{R}^n$ system, the system is linearly dependent. Any three vectors in $\mathbb{R}^2$ must be linearly dependent.
