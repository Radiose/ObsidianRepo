linearity
if $A \in \mathbb{R}^{m*n}$ and $u,v \in \mathbb{R}^n$
$A(u + v)=Au + Av$
$A(cU)=c(Au)$ for any constant $c \in \mathbb{R}$

The first application of this concept is for example, the linear system 
$2x_{1}+4x_{2}=9$
$4x_{1}+9x_{2}=3$

can be written as the [[vector]] equation 
$x_{1}\begin{pmatrix}2 \\ 4\end{pmatrix}+x_{2}\begin{pmatrix}4  \\ 9\end{pmatrix} = \begin{pmatrix}2 \\ 3\end{pmatrix}$
due to [[inner products]], we can rewrite this as $\begin{matrix}[2\ 4]  \\ [4\ 9]\end{matrix}$ $\begin{matrix}[x_{1} ]\\ [ x_{2}]\end{matrix}$ = $\begin{pmatrix}2  \\  3\end{pmatrix}$
which has the generic form ax + b where a is the matrix of coefficients, x is the matrix of x ,and b is the 2/3 matrix.
