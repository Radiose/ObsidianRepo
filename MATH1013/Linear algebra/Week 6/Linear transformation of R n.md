	Linear transformation
using concepts of [[linearity]],
A [[Transformation]] $T: \mathbb{R}^n\to \mathbb{R}^m$ is linear if 
$T(u+v) = T(u)+T(v)$
$T(cu)=cT(u)$
or equivalently, $T(cu+dv)=cT(u)+dT(v)$ for all
