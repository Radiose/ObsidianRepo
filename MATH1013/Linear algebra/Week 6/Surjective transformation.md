Surjective transformation
**When is T [[surjective function|surjective]]?** 
Is every element $\vec{b} \in \mathbb{R}^m$ in the format $\vec{b}=A \vec{x}$


# Formal
A function $T:V \to W$ is called surjective if $Range(T)=W$



An important thing to remember, is that a [[Transformation]] cannot be [[surjective function|surjective]] if there are more rows than columns. It is impossible for $\mathbb{R}^n \to \mathbb{R}^m$ to be surjective, as there will always be some information in the codomain that is not possible to be reached, as the [[span]] of n [[vector]]s cannot reach all m dimensions if m>n.
