Interpolation
Interpolation is fitting a function to a set of data points 
Given data $(t_{1},y_{1})\dots(t_{n},y_{n})$, find a function p(t) such that p(t) = y for all t
If you decide to use polynomial functions to interpolate, you always get linear constraints.

If your data points are weird, you may not get an answer for the function you have chosen. 

In this course, you typically use polynomials.
