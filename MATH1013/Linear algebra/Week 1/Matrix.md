A coefficient matrix of the system is the array of coefficients
$\begin{matrix}[a_{1},a_{2},a_{3}\dots] \\ [a_{m_{1}},a_{m_{2}},a_{m_{3}}\dots]\end{matrix}$


![[Pasted image 20260227113750.png]]
 The augmented matrix of the system is the array including the answers. 
 The augmented matrix contains all the information of the original linear system


Two lines cross each other when each equation is satisfied. This can be accomplished by finding a solution to a linear equation. If x and y both satisfy each equation, then thats the point they cross.
