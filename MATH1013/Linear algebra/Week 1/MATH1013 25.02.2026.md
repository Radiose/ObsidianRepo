Linear equations
an equation in unknowns in linear if it has the for $a_{1}x_{1}+a_{2}x_{2}\dots+a_{n}x_{n}=b$ 
where $a_{n}$ are constants, also known as the coefficients
the variables are the x's. 
Any function that includes $x_{1}*x_{2}$ is not included in this linear algebra 

$x_{1}+x_{2}$ = 2 is a linear equation.

Gauchian elimination
1: move rows with 0's in them to the bottom of the [[matrix]]
2: a pivot is a chosen part of a linear equation, that is used to eliminate variables in other equations
3:  use linear equations and row operations to eliminate other equations. Equations that have one x term and the answer being 0, have no real solutions and as a result have all coefficients replaced with 0 in the matrix.

4:  use columns that do not have a pivot in them to write that x in terms of the other x's. This gives you a row echelon form.  
5: once all pivots have been rescaled to 1, and the pivot is the only nonzero entry in that column, the matrix is in row reduced echelon form. 

4 equations and 3 variables have a very high chance of being an [[Inconsistent linear system]]. 

To determine whether a linear system is a [[Consistent linear system]] or an [[Inconsistent linear system]]. 

When an augmented matrix is in row echelon form, if there is a row with all zeroes and a 1 in the answer side, then it is an [[Inconsistent linear system]]. IE 
if there is a row that says $0=b$ and $b \not=0$, then the system is inconsistent, and vice versa. 


Example $\begin{matrix}[1,2,3| 3] \\ [0,1,2|4]  \\ [0,0,4|5]\end{matrix}$
From this, you can directly tell that there are three pivots. These three pivots are what allow you to solve the system backwards. 
EG for row three, you can tell that $x_{3}=\frac{5}{4}$. These pivots are fixed.
In this system, there is exactly one solution because there is exactly one pivot in each column. 

There is exactly one solution $\iff$ in [[row echelon form]], every column is occupied by a pivot. 

for another linear system 

$\begin{matrix}[1,0,3,4 | 2] \\ [0,0,2,1|3]  \\ [0,0,0,1 | 4]\end{matrix}$
In this equation, we can get an answer for x1, x3, x4, but because there is no answer for x2, it can be anything. For this reason, x2 can be anything, IE any real number. Therefore, there are infinitely many solutions to this equation because x2 is a free variable. 

A free variable is when there are no answers in a row reduced echelon form. 

Therefore there are infinitely many solutions $\iff$ there is a column without a pivot
