Degenerate orbitals 
orbitals with the same value of n in a hydrogen like system. They have the same energy level. By hydrogen like system, we refer to atoms with one electron.

All orbital sets in the same sublevel (1s, 2s, 2p, 3s, 3p etc) are still degenerate. 
 
 When an orbital is degenerate, it doesnt matter what orbital you first fill with electrons. Order after the initial does matter, but the first is irrelevant.
