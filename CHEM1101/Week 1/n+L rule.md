n+L rule
To determine the electron configurations for elements beyond Ar, it is necessary to satisfy the n+l rule which takes account of electron interactions. 

This rule requires that [[Orbital]]s with the lowest of (n+l) fill first. If two or more of these orbitals have the same value of, the of these, the orbital with the lowest value of n fills first.
