Angular momentum quantum number 
Defines the shape of the [[Orbital]]
allowed values of *I* are integers ranging from 0 to n-1
We use letters designations to communicate the different values of *I* and therefore, the shapes and types of orbitals

if *l* = 0 then s orbital
 = 1 then p orbital 
 = 2 then d orbital 
 = 3 then f orbital
