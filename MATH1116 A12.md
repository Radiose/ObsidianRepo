First, we establish that $(x,y) \mapsto \sum_{n=1}^\infty \frac{\sin(nx+y)}{n!}$ defines a function. 
We demonstrate this first by showing it converges absolutely. 
$\sum_{n=1}^{\infty}\left| \frac{\sin(nx+y)}{n!}\right| \leq \sum_{n=1}^\infty |\frac{1}{n!}|$ which converges. 
Because the convergence of a series is the limit of its partial sums, for all $x,y$ there is a unique limit of the sum thus a unique element of the codomain, thus we have established $(x,y)\mapsto \sum_{n=1}^\infty \frac{\sin(nx+y)}{n!}$ defines a function which we call $f:\mathbb{R}^2 \to \mathbb{R}$


Because a function is $C^1$ if both its partial derivatives exist, and are continuous, we test that each of the functions partial derivatives exist. In order to pass the derivative through the sum, we first demonstrate uniform convergence. 
Call $f_{n}(x,y)= \frac{\sin(nx+y)}{n!}$. Note that via the convergence of the series, $f_{n}\xrightarrow[n \to \infty]{}0$ pointwise. 

Thus  $\sup_{x \in\left[ -\frac{\pi}{2}, \frac{\pi}{2} \right]}\left\lvert  \frac{f(nx+y)}{n!}  \right\rvert \leq \left\lvert  \frac{1}{n!}  \right\rvert\xrightarrow[n \to \infty]{}0$ and similarly with respect to $y$ as well. 
Thus, $f_{n}(x)$ converges uniformly, so 
$\frac{ \partial f }{ \partial e_{1} }(x,y)= \sum_{n=1}^\infty \frac{\cos(xn+y)}{(n-1)!}$ which is continuous, as a sum of continuous functions are continuous.
